1. AI Driverとは

AI Driverは、AIホスト上で複数工程の仕事について計画・実行または委任・成果確認・継続を支援するSkill（指示文パッケージ）です。確認済みの公開候補には、公開者が運営するサーバー、APIエンドポイント、独自ログイン機能、アクセス解析コード、独立したデータベースは含まれていません。実際に利用できる機能は、利用者のAIホスト、接続ツール、権限に依存します。

2. 扱われる情報と収集

  • 公開者独自の収集： このSkillのインストールや利用そのものによって、プロンプト、文書、プロジェクト状態、ツールの結果がsilentlybeyondに送信されることはありません。確認済みパッケージには受信用エンドポイントも、公開者が運営するチャット・プロジェクト用データベースもありません。
  • AIホストと接続サービス： 利用するAIプラットフォームと利用者が別途許可したツールでは、会話内容、目的、完了条件、アップロードしたファイル、ツール入出力、決定事項、保存状態などが、各事業者の条件と設定に従って処理される場合があります。これはsilentlybeyondによる独自の収集とは異なります。
  • この掲載サイト： GitHub Pagesで配信しています。GitHubは、ログインの有無にかかわらず、セキュリティ目的でサイト訪問者のIPアドレスを記録します。処理・保管・利用者の管理方法についてはGitHubのプライバシーステートメントを参照してください。公開者独自の追跡スクリプト、解析ピクセル、フォーム送信機能は設けません。
  • 問い合わせ・フィードバック： GitHub Issueを作成すると、件名・内容・GitHubユーザー名が公開されます。パスワード、個人情報、機密文書、アカウント識別情報、健康情報、機微なプライバシー相談は投稿しないでください。 AIホストや接続先が保有するデータについては、各事業者の正式な窓口を利用してください。

3. 利用目的

AI Driverは、利用者の許可された目的の理解、必要な作業の計画、利用可能な権限での作業実行または委任指示の準備、完了条件に沿った結果評価、利用可能な保存記録からの再開を支援します。現在のパッケージに、公開者独自の広告配信、プロファイリング、データ販売機能はありません。

4. 情報の受領先

  • AIホスト事業者： 利用者の入力・生成結果や操作情報を処理する場合があります。
  • 接続アプリと保存サービス： 利用者の権限で実行する作業に必要な情報を受け取る場合があります。
  • GitHub： プライバシーポリシーのWebサイトと公開Issuesを提供します。
  • silentlybeyond： このSkill経由でAI会話やプロジェクト文書を受信しません。公開Issueに利用者が自ら投稿した情報は閲覧できる場合があります。

5. 保存期間

  • 公開者が運営するチャット・プロジェクト情報の保存： 現行Skillによる独自の収集・保存はないため、公開者側の保存期間はありません。
  • AIホスト・接続ツール・利用者自身の保存状態： 保管と削除は事業者・サービス・利用者設定に依存します。正確な期間は各サービスの最新の公開情報をご確認ください。AI Driverはその期間を定めたり保証したりできません。
  • GitHub Pagesの通信・セキュリティログ： GitHubが同社のプライバシーステートメントに従って保存・管理します。公開者は別途アクセスログをダウンロード・蓄積せず、GitHubの保管期間を管理しません。
  • 公開Issues： 投稿は編集・削除・アクセス変更等が行われるまでGitHub上で公開され、GitHubのポリシーに応じてその後も記録が保持される場合があります。公開者は独自の非公開サポートDBに複製しません。機密情報は投稿しないでください。

6. 利用者による管理

利用者は、AIホストに共有する情報と接続ツールの許可を選べます。会話・保存記録の閲覧・削除、権限の解除、Skillの利用停止は各サービスの機能によって行えます。GitHubの機能が許す範囲で自身のIssueを編集したり、機密情報を再投稿せず削除依頼をIssueで提出できます。silentlybeyondは別事業者のデータを直接取得・削除できません。

7. 機密情報と安全性

認証情報、カード番号、公的識別番号、保護対象の医療情報などをAI Driverの作業文に入力しないでください。このSkillは行動指針であり、技術的なセキュリティ境界や追加権限を設けるものではなく、誤りのない動作も保証しません。

8. 改定

データ取扱いやパッケージ機能に重要な変更がある場合、このポリシーを改定し最終更新日を更新します。GitHub PagesやIssuesの利用停止・変更時にも必要に応じて内容を見直します。
