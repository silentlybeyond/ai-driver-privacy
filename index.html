AI Driver — Privacy Policy

Publisher: silentlybeyond
Last updated: October 20, 2026
Effective: When first published on this site
Contact: GitHub Issues — public messages only

1. What AI Driver is

AI Driver is a skills-only set of instructions intended to help users plan, execute or delegate, check and continue multi-step work through their AI host. The reviewed publication candidate does not package an AI Driver-operated server, API endpoint, sign-in system, analytics code or independent database. Actual capabilities depend on the user's AI host, connected tools, and permissions.

2. Information involved and collection

  • Publisher-operated collection: Installing or using this Skill does not itself send your prompts, documents, project state or tool results to silentlybeyond. The reviewed package has no endpoint for silentlybeyond to receive these data, and no publisher-run project or chat database.
  • AI host and connected services: Your selected AI platform and separately authorized tools may process conversation content, goals, completion criteria, uploaded files, tool inputs and results, decisions and saved continuity state, according to their own terms and settings. This processing is not a separate collection by silentlybeyond.
  • This policy website: It is served using GitHub Pages. GitHub logs visitors' IP addresses for security purposes, including when users are not signed in. GitHub's privacy statement describes GitHub's processing, retention and controls. The publisher does not add its own tracking scripts, analytics pixels or form submissions to these pages.
  • Questions and feedback: If you voluntarily open a GitHub Issue, its title, content and your GitHub username are publicly visible. Do not put passwords, personal data, confidential files, account identifiers, health information or sensitive privacy requests in public Issues. Contact the relevant AI host or connected provider directly about data they hold.

3. Why information is processed

AI Driver helps your authorized AI host understand the requested goal, plan necessary tasks, use available permissions to act or prepare delegated instructions, evaluate results against completion criteria and resume when relevant saved state is available. The package has no publisher-run ad targeting, profiling or independent data sale mechanism.

4. Who receives information

  • Host providers: Your AI platform may process your inputs, generated responses and related activity.
  • Connected apps and storage providers: When invoked under your authorization, those providers may receive the data needed to complete your task.
  • GitHub: Hosts this public policy site and public repository Issues, as described by its privacy statement.
  • silentlybeyond: Does not receive your AI conversation or project files via this Skill. The publisher may see information you choose to post publicly in this repository's Issues.

5. Retention

  • AI Driver publisher-operated project/chat records: None are collected or retained by this skills-only package. No publisher-side retention period applies to those categories.
  • AI host, connected tools, and user-owned saved state: Retention and deletion depend on the particular host/provider and your account settings. Check each provider's published retention policy; AI Driver cannot set or guarantee those periods.
  • GitHub Pages connection and security logs: GitHub retains and controls such logs under its privacy statement. The publisher does not separately download or keep a website visitor log, and does not set GitHub's retention period.
  • Public Issues: Content remains visible on GitHub until edited, removed or access changes, and GitHub may retain information subject to its policies. The publisher does not copy Issues into an independent private support database. Do not use public Issues for confidential inquiries.

6. Your controls

You can choose what to share with the AI host and whether to authorize connected tools. Use your host/provider controls to access or delete chats and saved records, revoke permissions and discontinue the Skill. You can edit your own GitHub Issue content where GitHub permits or request removal through an Issue without repeating confidential details. silentlybeyond cannot access or erase records held by separate AI or storage providers on your behalf.

7. Sensitive data and security

Do not enter authentication secrets, payment-card numbers, government identifiers, protected medical information or other sensitive data into an AI Driver task. This Skill provides behavioral guidance and does not create a technical security boundary, grant permissions or guarantee error-free results.

8. Changes

If data handling or package capabilities change materially, this policy will be updated and its last-updated date revised. The publisher may cease using GitHub Pages or Issues with a corresponding policy update.

9. Contact

Public feedback route: GitHub Issues for AI Driver's privacy-policy repository

GitHub Issues are public, not a confidential channel. Do not include personal or sensitive information. For private data-access, deletion or security requests concerning the AI host or connected tools, use that provider's official privacy/support channels.
